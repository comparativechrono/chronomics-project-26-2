1. Align

An alignment writes sequences one above another, adding gaps (-) so that the letters in each column descend from the same letter of the ancestors' sequence. kalign aligns many sequences at once: it first measures how alike each pair is, builds a rough tree from that, and then aligns the most similar sequences first, adding the others one group at a time.

cd ~/project
mkdir -p alignments
kalign -i /data/examples/fnss/orthologs/BHLHE41_ncbi_mammals.fasta -o alignments/BHLHE41_ncbi.afa

-i is the input, -o the output: an aligned FASTA file (.afa). It takes a few seconds. kalign first prints its name and how to cite it, a warning that it cannot use the fast instructions of your processor (AVX2 – it runs in the browser, so this is expected), and then its progress. Look at the result:

grep -c ">" alignments/BHLHE41_ncbi.afa
seqtk seq -l0 alignments/BHLHE41_ncbi.afa | head -6 | cut -c 1-70
seqtk comp alignments/BHLHE41_ncbi.afa | cut -f 2 | sort | uniq -c

The sequences now have gaps, and – the point of an alignment – they are all the same length. (seqtk comp counts the gaps in the length.) The Files tab shows an alignment in colour, column by column:

open alignments/BHLHE41_ncbi.afa
Check

240 sequences, every one 820 characters long with its gaps – longer than any of the proteins, because each species' insertions open a gap in all the others. The first columns are mostly gaps: a few proteins start earlier than the rest.

3. Read the alignment into R

R has no function to read a FASTA file without extra packages – so write one. A function of your own is made with function( ) and given a name; afterwards you use it like any other. This one reads the lines of a file, finds the name lines, keeps the first word of each name, and pastes together the lines of each sequence:

# read a FASTA file into a named vector: one sequence per species
read_fasta <- function(path) {
  x <- readLines(path)
  h <- grep("^>", x)                        # which lines are name lines
  ids <- sub("^>(\\S+).*", "\\1", x[h])      # the first word of each name, without the >
  ends <- c(h[-1] - 1, length(x))            # each sequence ends just before the next name
  seqs <- mapply(function(a, b) paste(x[(a + 1):b], collapse = ""), h, ends)
  setNames(toupper(seqs), ids)
}
aln <- read_fasta("~/project/alignments/BHLHE41_ncbi.afa")
length(aln)
head(nchar(aln))

aln is a vector of 240 sequences, each named by its species: aln["Mus_musculus"] is the mouse's. Now split every sequence into its letters, one per column, and stack them into a matrix – a table with a row for each species and a column for each column of the alignment:

m <- do.call(rbind, strsplit(aln, ""))
dim(m)
m[1:4, 1:12]

strsplit(aln, "") cuts each sequence into single letters; rbind binds them as rows; dim gives the numbers of rows and columns. m[1:4, 1:12] is rows 1 to 4 and columns 1 to 12 – in R, the row comes before the comma and the column after it, and the rows can be picked by name too: m["Homo_sapiens", 1:12].

4. Find the column of P384

In the human row, the columns with a letter (not a gap) are, in order, human positions 1, 2, 3 … 482. So the 384th column with a letter in the human row is the column of P384:

human_cols <- which(m["Homo_sapiens", ] != "-")
length(human_cols)
col384 <- human_cols[384]
col384
table(m[, col384])

which gives the numbers of the columns for which the test is TRUE; table counts the values in the column of P384, over all 240 species.

Check

human_cols has 482 columns – one for each amino acid of the human protein. In all 240 species the amino acid in the column of P384 is P.

5. Is the alignment right there?

An aligner can be wrong, and so can a prediction of a protein: a species could show "P" in this column only because something else was pushed into it. Look at the 21 columns around P384 (from human position 374 to 394) in a few species – paste(…, collapse = "") glues each row's letters into one string:

window <- human_cols[374:394]
some <- c("Homo_sapiens", "Mus_musculus", "Canis_lupus", "Loxodonta_africana", "Marmota_marmota")
apply(m[some, window], 1, paste, collapse = "")

Where a species has a gap in the window (as the mouse does) it lacks an amino acid there. To check every species, measure how many of the 21 positions match the human – the window identity. apply(…, 1, …) applies a function to each row of a matrix; here, a function that compares the row with the human window and takes the mean of TRUE (1) and FALSE (0):

human_window <- m["Homo_sapiens", window]
win_id <- apply(m[, window], 1, function(row) mean(row == human_window))
summary(win_id)
sum(win_id < 0.5)
Check

The window identity goes from about 0.76 to 1, with a median of 1: every species matches the human at most of the 21 positions, so the column of P384 is well aligned in all of them. None is below 0.5.

Keep the result as a table – a data frame: named columns, one row per species – and save it as a file:

calls <- data.frame(species = rownames(m), residue = m[, col384],
                    window_identity = round(win_id, 2), row.names = NULL)
calls$ok <- calls$window_identity >= 0.5 & calls$residue != "-"
head(calls)
table(calls$residue, calls$ok)
write.table(calls, "~/project/results/BHLHE41_P384_ncbi.tsv", sep = "\t", quote = FALSE, row.names = FALSE)

calls$ok is a new column: TRUE where the window identity is at least 0.5 and the species has an amino acid (not a gap) in the column. & means "and".
