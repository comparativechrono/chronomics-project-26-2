2. One function for any position

Open the notebook of this stage:

A notebook starts empty: what you made in stage 3's notebook is not here. Run the read_fasta function again first (copy it from stage 3, or use the button). Then make a second function out of the steps of stage 3: give it an alignment file and a human position, and it returns a data frame with each species' amino acid in that column and the window identity around it. max and min keep the window inside the protein:

read_fasta <- function(path) {
  x <- readLines(path)
  h <- grep("^>", x)
  ids <- sub("^>(\\S+).*", "\\1", x[h])
  ends <- c(h[-1] - 1, length(x))
  seqs <- mapply(function(a, b) paste(x[(a + 1):b], collapse = ""), h, ends)
  setNames(toupper(seqs), ids)
}
# the amino acid of every species in the column of human position pos, with the window identity
call_site <- function(file, pos, ref = "Homo_sapiens") {
  aln <- read_fasta(file)
  m <- do.call(rbind, strsplit(aln, ""))
  human_cols <- which(m[ref, ] != "-")
  col <- human_cols[pos]
  window <- human_cols[max(1, pos - 10):min(length(human_cols), pos + 10)]
  human_window <- m[ref, window]
  win_id <- apply(m[, window], 1, function(row) mean(row == human_window))
  data.frame(species = rownames(m), residue = m[, col], window_identity = round(win_id, 2),
             ok = win_id >= 0.5 & m[, col] != "-", row.names = NULL)
}

4. Do the two sources agree?

For the species in both sources, do NCBI and TOGA give the same amino acid? merge joins two tables by the columns they share – here the mutation and the species:

ncbi_calls <- ok[ok$source == "ncbi", c("variant", "species", "residue")]
toga_calls <- ok[ok$source == "toga", c("variant", "species", "residue")]
both <- merge(ncbi_calls, toga_calls, by = c("variant", "species"), suffixes = c("_ncbi", "_toga"))
nrow(both)
table(both$residue_ncbi == both$residue_toga)
Check

944 pairs, and the two sources agree in every one. Two methods built from partly different genomes and different ways of finding genes give the same answer: you can trust it.

So combine them into one table of species: every species in either source, with its amino acid (TOGA's where there is one, otherwise NCBI's – they never disagree). all = TRUE keeps the species found in only one of them; ifelse chooses, row by row:

combined <- merge(ncbi_calls, toga_calls, by = c("variant", "species"), all = TRUE, suffixes = c("_ncbi", "_toga"))
combined$residue <- ifelse(is.na(combined$residue_toga), combined$residue_ncbi, combined$residue_toga)
combined$source <- ifelse(is.na(combined$residue_ncbi), "toga", ifelse(is.na(combined$residue_toga), "ncbi", "both"))
table(combined$variant, combined$residue)
write.table(combined[, c("variant", "species", "residue", "source")], "~/project/results/species_residues.tsv",
            sep = "\t", quote = FALSE, row.names = FALSE)

5. How conserved, compared with what?

"Conserved" means more than "the same in many species": it means more alike than the rest of the protein. Measure every position of a protein the same way – the share of species that have the human amino acid – and see where the mutation's position falls. sapply applies a function to each value of a vector (here, each column that holds a human amino acid) and collects the answers:

profile <- function(file, ref = "Homo_sapiens") {
  aln <- read_fasta(file)
  m <- do.call(rbind, strsplit(aln, ""))
  human_cols <- which(m[ref, ] != "-")
  same <- sapply(human_cols, function(k) mean(m[, k] == m[ref, k]))
  data.frame(position = seq_along(human_cols), human_residue = m[ref, human_cols], same = same, row.names = NULL)
}
p <- profile("~/project/alignments/GRM1_ncbi.afa")
p[458, ]
median(p$same)
mean(p$same < p$same[458])
plot(p$position, 1 - p$same, type = "h", col = "grey50", xlab = "Position in human GRM1 (mGluR1a)",
     ylab = "Share of species with another amino acid", main = "GRM1 in 256 mammals")
points(458, 1 - p$same[458], col = "red", pch = 19)

mean(p$same < p$same[458]) is the share of positions that are less conserved than S458. The plot shows the other side of the coin: for each position, the share of species whose amino acid differs from the human one, as a vertical line (type = "h") – conserved positions are low, variable ones stand out as spikes.

Check

Half of GRM1's positions have the human amino acid in at least 97% of species. S458 has it in only 43%: just 3.3% of GRM1's positions are less conserved. Far from conserved, S458 is among the most variable positions of the protein. Most of the positions more variable still are at the very start of the protein or in mGluR1a's long tail inside the cell (after position 880), where the species' proteins differ in length; only a few are, like S458, in the large part outside the cell that binds glutamate.
